# Foro-Windows-Forms-en-C-
Agenda de Contactos en Windows Forms 

📘 Agenda de Contactos – Windows Forms

Para esta actividad desarrollé una aplicación de escritorio tipo Agenda de Contactos utilizando Windows Forms en C#. El objetivo principal del proyecto es aplicar los fundamentos de la Programación Orientada a Objetos (POO), el manejo de eventos y la creación de interfaces gráficas interactivas.

La aplicación permite al usuario gestionar una lista básica de contactos mediante una interfaz sencilla e intuitiva. Entre sus funcionalidades principales se encuentran:

Agregar nuevos contactos:
El usuario puede introducir nombre, teléfono y correo electrónico en los campos de texto correspondientes. Al presionar el botón "Agregar", el sistema crea un nuevo objeto de tipo Contacto y lo almacena en una lista interna.

Visualización de contactos:
Los contactos registrados se muestran dinámicamente en un control ListBox, permitiendo al usuario visualizar la información organizada de cada registro.

Eliminación de contactos:
El usuario puede seleccionar un contacto de la lista y eliminarlo mediante el botón correspondiente, actualizando tanto la lista interna como la interfaz gráfica.

Validación de datos:
Antes de guardar un contacto, la aplicación verifica que todos los campos estén completos. En caso contrario, se muestra un mensaje de advertencia para evitar registros incompletos.
